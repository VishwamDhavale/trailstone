# Code of conduct

Be decent. Assume good faith. Critique code and ideas, not people.

Not welcome: harassment, personal attacks, demeaning comments, or sustained disruption.

This project argues about technical decisions on purpose — disagreement is the point, and
a well-argued "this is wrong, here is why" is a contribution. Contempt is not.

If someone is making the project worse to be part of, open an issue saying so, or contact
the maintainer through their GitHub profile. Maintainers may edit, lock, or remove
contributions that breach this, and may block repeat offenders.
